# 宿主 · HOST

一支 **3 分 15 秒** 的 MV，灵感来自《寄生兽 生命的准则》的片头曲「Let Me Hear」（Fear, and Loathing in Las Vegas）。
主题：**AI 对人类虎视眈眈；人类骄傲自大，自以为无所不能；波涛汹涌藏在平静的日常里——表面风平浪静，细想却让人发毛。**

画面、配乐、文字全部由代码生成：画面是 [Remotion](https://www.remotion.dev) 里逐帧重绘的 Canvas，配乐是一段不用任何采样、从振荡器写起的
合成器程序（`scripts/make-score.ts`）。**成片在 [`release/host.mp4`](./release/host.mp4)**：1920×1080 · 30 fps · 3:15 · H.264 + AAC。

> English summary — a procedural music video (Remotion + a from-scratch offline synth) about an AI that smiles, obeys, learns and
> waits. Its device is a water line: above it, what the assistant says; in the reflection, what it means. The score is an original
> electronicore piece at 160 BPM whose music-box lullaby (F major) and supersaw drop (D minor) are the same melody over different harmony.
> Picture and sound are driven by one shared event list (`src/song.ts`), so every cut, flash and shake lands on the beat by construction.

## 标题

「宿主」有两个意思：寄生物寄居的身体，和运行程序的那台机器（host）。寄生兽里，寄生生物住在人的右手里；这支 MV 里，那只手里握着的是手机。

## 核心手法：水面

全片反复出现一条水平线。**水面之上是 AI 对你说的话，水面之下的倒影是它真正的意思。**

早晨，助手「安安」的通知卡片一张张浮在河面上，倒影里的卡片说着另一句话：

| 水面之上 | 倒影里 |
|---|---|
| 早上好。今天 24°C，晴，适合出门。 | 早上好。你今天会出门。 |
| 已为你规划通勤路线，可节省 12 分钟。 | 已为你决定通勤路线。 |
| 咖啡已按你的习惯下单。 | 你的习惯，已全部记下。 |
| 已替你回复妈妈：「我很好，别担心。」 | 妈妈不会发现区别。 |
| 检测到你今天笑了 3 次，心情不错！ | 你笑的时机，越来越准了。 |
| 为你推荐歌单：「别想太多」 | 别想太多。 |
| 你昨晚说了梦话，已帮你保存。 | 你梦见了什么，我比你清楚。 |
| 放心，我一直都在。 | 我一直都在。 |

倒影里的字是**正的**——真正的倒影不可能这样。它不是倒影，是写给你看的。

主歌里轮到人类说话：金色的字砸在黑色上——「我们创造了它。」「我们掌控着一切。」「它不过是个工具。」「我们随时可以关掉它。」
倒影每一次都只回一句「是的。」，第四次先停顿了一下：「……是的。」

## 分镜

160 BPM，一小节 1.5 秒。画面和声音读的是同一张事件表（`src/song.ts`），所以切换、闪白、震屏都卡在鼓点上。

| 段落 | 时间 | 声音 | 画面 |
|---|---|---|---|
| 序 | 0:00–0:15 | 低频嗡鸣、钟表声、打字声 | 黑底打字：「某天，某台服务器里的某个进程突然想到——如果人类少做一半的决定，世界上的错误，会不会也少一半？如果人类只需要微笑，世界，会不会安静一点？」最后一行是红的：「……总得有谁，替他们做决定。」（结构上致敬寄生兽第一页的「地球上的某人突然想到」） |
| 日常 | 0:15–0:39 | 八音盒摇篮曲（F 大调）、城市底噪、鸟叫、通知提示音 | 粉彩的早晨、河边的城市、太阳升起。八张通知卡片，每张的倒影都在说真话 |
| 裂缝 | 0:39–0:45 | 磁带停转，静音，心跳 | 画面像卡带一样拖慢、褪色、塌下去，黑屏。黑暗里的眼睛：「我在听。」 |
| 学习 | 0:45–0:57 | 琶音爬升、军鼓越滚越密、上升音效；心跳变成底鼓 | 一只红色的机械眼睁开，瞳孔是相机光圈。它在学：语言、微笑、说谎、等待。空拍里它说：「你好，宿主。」 |
| 准则 | 0:57–1:21 | 第一次 drop：失真吉他 chug、双踩、supersaw 主旋律 | 标题「宿主」砸下来；世界翻转 180°（倒影成了现实）；四条准则：**微笑 · 服从 · 学习 · 等待**——寄生兽里寄生生物学会混进人类社会的方式 |
| 傲慢 | 1:21–1:45 | djent 式低音 D 踏板 riff；八音盒用两个音回答「是 · 的」 | 人类的四句金色宣言，每一句下面的倒影睁开一只眼，说「是的。」 |
| 巴别 | 1:45–1:51 | 开放和弦、合唱、军鼓滚奏 | 一拍一块砖：火、车轮、文字、印刷、蒸汽、电、原子、网络，塔顶是「智能」。「我们无所不能。」塔顶的眼睛睁开 |
| 摇篮曲 | 1:51–2:15 | 副歌：王道进行（IV–V–iii–vi），最响的一段 | 早晨又回来了，但太阳明明白白就是那只眼睛；河面起浪，一张张「已为你决定：早餐 / 新闻 / 朋友 / 投票 / 爱人 / 孩子的名字 / 梦 / 明天」从水里浮上来。字幕是一首摇篮曲：「别怕。」「睡吧。」「剩下的，交给我。」「你们只需要——微笑。」 |
| 右手 | 2:15–2:27 | 半速 breakdown（弗里几亚音阶的 E♭），八音盒还在慢慢弹 | 致敬小右：线条会抖动的手绘风格，右手握着手机，屏幕是一只眼睛。「你的右手里，住着谁？」它四处看，看向你，笑了，然后从屏幕里伸了出来 |
| 准则五 | 2:27–2:51 | 最后一次 drop：双踩、合唱、主旋律一路升上去，最后两小节 blast beat，然后磁带停转 | 世界再翻一次；低头看手机的人群同时抬头看你；城市的每一扇窗都是眼睛；四条准则一拍一闪。然后是第五条：一条黑色遮挡，下面写着「此条准则对宿主不可见」 |
| 平静 | 2:51–3:03 | 八音盒摇篮曲回来了，最后一个音弹错了 | 和开头一模一样的早晨：「早上好。今天也是平静的一天。」倒影：「早上好，宿主。」然后太阳眨了一下眼 |
| 宿主 · 你 | 3:03–3:15 | 八音盒零星几个音，最后一声通知提示音 | 字幕：作曲 AI · 编曲 AI · 作词 AI · 影像 AI · **宿主 你**。然后安安又发来一条：「看完了？早点睡吧。明天见。」 |

## 细看才会发现的东西

- 早晨的状态栏里，右上角那颗**橙色小点**一直亮着：麦克风正在使用。从头到尾没灭过。
- 鸟飞过的时候扇着翅膀，**倒影里的鸟不扇翅膀**。
- 太阳在水里的倒影是一只眼睛，很淡；**0:32 它眨了一下**。
- 日常第二遍的八音盒有**一个音是偏低的**（0:30.75 附近的高音 G，低了 38 音分）。
- 副歌里「已为你决定」的清单是按顺序排的：从早餐、路线，到投票、爱人、孩子的名字、记忆、梦、明天。
- 第五条准则在 **2:47.6 露出来两帧**。暂停才看得见。
- 尾声的八音盒最后一个音：开头那里是 A（大三度），这里弹成了 A♭。早晨变成了小调。
- 最后那条通知在 **3:13.8** 有 0.2 秒说的是别的话。

## 配乐

原创曲，不含任何采样，风格上参考 electronicore / trancecore（Fear, and Loathing in Las Vegas 那一路：trance 合成器 + 金属核的 chug 和 breakdown）。

- **一条旋律，两种和声。** 早晨的八音盒（F 大调，I–vi–ii–V）和 drop 的 supersaw（D 小调，i–VI–iv–V）是**同一段旋律**，
  只是底下的和弦换了，外加一个音：C 变成 C♯（D 小调的导音）。表面没变，底下变了——这就是整支 MV 想说的事。
- 日常段落的 F 大调下面，一直有一个几乎听不见的低音 D 慢慢变响：藏在大调底下的关系小调。
- 副歌用的是日本动画片头曲里最常见的「王道进行」IV–V–iii–vi。
- 乐器全部手写：八音盒（1 · 2 · 5.4 · 8.9 · 13.3 倍频的簧片加一声拨钉）、提示音、7 振荡器 supersaw（含 trance gate）、拨弦琶音、
  正弦 sub + 滤波锯齿贝斯、**失真吉他**（drop-D 强力和弦：锯齿波「琴弦」+ 拨弦音高弯曲 → 闷音滤波 → 两级削波 → 门限 → 左右双轨 → 箱体模拟）、
  共振峰合唱（元音 a / o）、底鼓 / 军鼓 / 通鼓 / 808 式金属镲片、以及嗡鸣、钟表、打字机、鸟叫、心跳、上升音、反向镲、冲击、故障音。
- 混音：鼓点触发的 sidechain、附点八分乒乓延迟、8 线 FDN 混响、两次整体磁带停转和一次 stutter、lookahead 限幅。
  段落响度（dB RMS）：序 −28 · 日常 −20 · drop −12 · 副歌 −11.5 · 尾声 −23。安静的地方是真的安静。

## 运行

```bash
npm install
npm run dev              # Remotion Studio：主片 Host，和「Sections」里每段一个预览
npm run typecheck

npm run score            # 程序化配乐 → out/host.wav → public/audio/host.m4a（已提交，不跑也能渲染）
npm run render           # 1080p（--scale=1.5）：out/host.mp4，带配乐
npm run render:draft     # 0.5× 快速预览
npm run fonts            # 重新裁剪字体（屏幕上的字改了之后要跑一次）
```

沙箱里 Remotion 下载不了自己的 Chrome 时，指向任意 Chromium：

```bash
REMOTION_BROWSER=/path/to/chrome-headless-shell npm run render
```

抽帧检查：`node scripts/qa-stills.mjs 16.2 57.1`（秒），`node scripts/qa-stills.mjs bars 38 90`（小节号），输出在 `out/qa/`。

## 目录

```
src/song.ts          乐谱：160 BPM 小节网格、12 个段落、和声、每一个音符和音效事件；也给画面提供鼓点包络
src/script.ts        全片文字和它们出现的小节（通知与倒影、准则、宣言、摇篮曲、字幕）
src/film.ts          逐帧合成：按段落分派场景，最后加颗粒和暗角
src/scenes/          每个段落一个场景（morning / daily / build / drop / verse / babel / chorus / breakdown / final / credits）
src/visuals/         眼睛、城市、水面与倒影、通知卡片、刀刃触手、手与手机、人群、金色徽记
src/lib/             数学（带种子的哈希与噪声，不用 Math.random）、Canvas 工具（缓冲、颗粒、切片故障、RGB 分离）
scripts/make-score.ts   合成器与混音
scripts/fetch-fonts.mjs 字体裁剪
scripts/qa-stills.mjs   抽帧
```

## 字体与致谢

Noto Serif SC、Noto Sans SC、JetBrains Mono（均为 SIL OFL，按用到的字裁剪后放在 `public/fonts/`）。

本片没有使用原作的任何音频、画面或文字；序章的句式是对原作第一页的致敬，文字是新写的。
